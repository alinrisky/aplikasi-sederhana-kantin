# KantinKu - Aplikasi Penjualan Kantin

Aplikasi penjualan kantin berbasis web dengan dua peran: Kasir dan Owner.

## Fitur
- Login demo (peran Kasir dan Owner)
- Daftar menu per kategori (Makanan, Minuman, Snack, Buah-buahan)
- Keranjang dan pembayaran (Tunai, QRIS, Transfer Bank - simulasi)
- Struk transaksi dan stok otomatis berkurang
- Owner dapat menambah, mengubah, dan menghapus menu
- Halaman transaksi dan laporan

## Teknologi
HTML, CSS, JavaScript

## Cara Menjalankan
Buka file `front-end.html` di browser.
